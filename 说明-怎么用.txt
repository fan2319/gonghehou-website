一、怎么用（三步）
================================================================

1. 把整个文件夹放到 GitHub 仓库根目录
   （如果是新建仓库，目录结构就是仓库结构）

2. Netlify → Add new site → Import an existing project → 选仓库
   → Deploy

3. 开启后台（如果之前那个站已经开过，同一账号可复用）：
     Netlify 后台 → Site configuration → Identity → Enable Identity
     → Git Gateway → Enable Git Gateway
     → 邀请自己（Invite users），邮件里点链接设密码
     → 访问  你的域名/admin/  登录

二、后台能做什么（这是本次的重点）
================================================================

【A. 产品中心 —— 完整增删改查】

后台 → 🛍️ 产品中心（增删改查）

  新增商品：滚到「商品列表」，点 Add
  删除商品：每条右上角垃圾桶图标
  调整顺序：每条左侧上下箭头（或用「排序」数字，小的在前）
  临时隐藏：把「上架」取消勾选 —— 前台立刻消失，后台数据还在
  改参数：参数表可增删行，参数名自己写

一个商品包含：
  内部标识 / 所属品类 / 排序 / 上架开关 / 主图
  名称 · 副标题 · 描述（各三语）
  参数表（可增删行，每行也是三语）

【加瓷器的例子】
  1. 先在「品类分组」里确认有 porcelain（已经有了）
  2. 商品列表点 Add，填：
       id: porcelain-vase-01
       category: porcelain          ← 注意要和品类分组的标识一致
       order: 1
       published: 勾选
       image: 上传瓷器照片
       name: 中文「青花瓷瓶」/ en / ru
       specs: 可自定义行，比如
              参数名「尺寸」值「高 32cm」
              参数名「工艺」值「手工拉坯 · 釉下彩」
  3. Save → Netlify 自动重新部署 → 前台「瓷器与工艺品」分类下出现

【加泵的例子】同理，category 填 machinery。

【B. 站点内容 —— 所有文字都能改】
  首屏大标题 / 副标题 / 背景图
  关于我们 标题 · 正文 · 配图 · 经营范围清单（可增删）
  服务能力 标题 · 导语 · 流程步骤（可增删，自动编号）· 底部说明
  为什么选择我们（可增删条目）
  合作条款（可增删条目）
  常见问题（可增删问答）
  联系方式（地址、两个电话、两个邮箱、微信）

【C. 实时预览 —— 边改边看】
在后台编辑时，右侧就是预览面板：
  产品中心：按前台真实卡片样式渲染，改名字改图立刻变；
            下架的商品会变灰并标注「已下架」；
            三语并排显示，方便检查有没有漏翻。
  站点内容：首屏（带背景图）、关于、经营范围、流程步骤、
            为什么选我们、条款、FAQ、联系方式，全部渲染。
⚠️ 不用保存、不用等 Netlify 部署，改一个字右边就变。

五、上线后必做
================================================================

1️⃣ 把网站域名加进 Worker 的 ALLOWED_ORIGINS
   Cloudflare → gonghehou-form → Settings → Variables
   ALLOWED_ORIGINS = https://你的站.netlify.app
   不加的话表单提交会被来源校验挡掉，客户填了收不到。

2️⃣ 表单目前指向
   https://gonghehou-form.tunnir243.workers.dev
   （在 assets/js/main.js 顶部的 ENDPOINT，改这里可换）
   提交后：Telegram 群收到两条（摘要 + 单独一条联系方式，
   手机上长按即可复制去拨号），同时发邮件备份。

3️⃣ 图片如果没显示
   检查 assets/img/ 里的文件是否真的 Push 上去了。

六、本地怎么预览
================================================================
【方式一】单文件版（部署包-昭盛元新/index.html）
  双击就能打开，不需要服务器。数据已内联，图片已内嵌。
  适合发给客户看、手机上打开。

【方式二】多文件版
  浏览器直接双击会因 CORS 读不到 data/*.json。
  在本地起个服务即可：
    python -m http.server 8000
  然后访问 http://localhost:8000
